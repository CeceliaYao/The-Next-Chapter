# Assets

Drop the team's photos into `photos/` and videos into `video/`, using the exact filenames listed in the main [README](../README.md#adding-the-real-photos--videos).
Anything missing shows a placeholder in the game, so you can add files one at a time.

- Photos: `.jpg`, landscape (about 1200 × 730 px)
- Videos: `.mp4` with **H.264** video, landscape 16:9, 5–20 seconds
